# Tóm tắt Session Làm việc - AppAuthService (Tích hợp Agent)

**Thời gian thực hiện**: 28/05/2026

## 1. Mục tiêu và Kết quả đạt được
- Tạo thành công tài liệu đặc tả tích hợp dành cho AI Agent bên ngoài: [authservice.md](authservice.md).
- Thiết lập bộ quy chuẩn rõ ràng cho các Agent khác (ví dụ: Inventory, POS) dễ dàng kết nối và tương tác với hệ thống `AppAuthService` (AS).
- Đóng gói toàn bộ cấu trúc API, dữ liệu phản hồi chuẩn (`BOProcessResult`), các mô hình Class bằng C# và TypeScript, cùng sơ đồ xử lý lỗi và Refresh Token Rotation.

## 2. Chi tiết Đặc tả trong File authservice.md

### A. Cấu hình & Headers
- **x-api-key**: Định danh qua khóa đăng ký doanh nghiệp (`RegKey`).
- **AppNumber**: Xác định ứng dụng đích mà user đang truy cập (ví dụ: `"FnBInv"`).

### B. Cấu trúc Mô hình & Dữ liệu
- Đồng bộ hóa các Class dùng cho C# (.NET) và TypeScript/JavaScript:
  - `BOProcessResult<T>`: Wrapper chứa thông tin thành công/thất bại, mã lỗi logic, và payload.
  - `LoginRequest`, `RefreshTokenRequest`, `SwitchAppRequest`.
  - `LoginResponse`, `UserData`, `JwtData` (gồm `Jwt` cho Access Token và `Rft` cho Refresh Token).
  - `ObjectRight`: Chứa các cờ quyền CRUD chi tiết (`CanList`, `CanRead`, `CanCreate`, `CanUpdate`, `CanDelete`).

### C. Luồng Xử lý cho Client Agent
- **Refresh Token Rotation**: Đặc tả chi tiết vòng lặp Refresh Token, cơ chế chống tấn công tái sử dụng token (Token Reuse Attack) để tự động đăng xuất user nếu phát hiện hành vi bất thường.
- **Phân quyền phía Client**: Hướng dẫn xây dựng Helper kiểm tra quyền nhanh dạng O(1) từ `mergedRights` mà không cần gọi API kiểm tra liên tục lên server.
- **SSO / Switch App**: Hướng dẫn chuyển đổi ứng dụng nhanh chóng qua `/api/auth/switch-app`.
- **HttpClient Middleware**: Cung cấp mã mẫu hoàn chỉnh về `AuthTokenHandler` kế thừa từ `DelegatingHandler` trong C# để xử lý tự động inject JWT và bắt mã `401` để tự động refresh token.
